# LifeLibra Lab

> 科研，不必一个人开始。

LifeLibra Lab 是一个开放的 AI 科研社区。我们希望连接真正对研究感兴趣的伙伴，通过论文阅读、问题讨论、实验复现、系统实现与论文写作，把想法推进为可靠、可验证的研究成果。

我们面向所有高校和不同背景的研究者，不限制学校、专业或当前身份，也不要求申请者已经发表论文。相比已有成果，我们更看重真实的研究兴趣、可靠的行动力，以及长期协作的意愿。

## Research

我们目前关注以下四个研究方向：

### 1. Agent Harness

研究像 Codex 这样的智能体系统如何被构建，以及上下文组织、工具调用、任务规划、记忆、反馈回路与运行环境如何共同释放基础模型的潜力。

### 2. Agent Training

研究模型如何从随机初始化的参数出发，通过预训练、后训练、强化学习、过程监督与合成数据，逐步获得推理、行动和协作能力。

### 3. Reliable Medical VLM Reasoning

训练医学视觉语言模型依据临床指南与可追溯证据进行推理，让诊断建议更有依据、更可解释，并能够接受临床人员的审查与验证。

### 4. Edge-Adaptation Medical VLM

设计轻量、高效的本地适配框架，让医院在保护院内数据的前提下，利用有限数据快速完成特定疾病、设备与人群的模型适配。

## Recruitment

LifeLibra Lab 正在招募对 AI 科研有持续兴趣的新成员。我们希望与你一起围绕明确的问题组成小组，通过定期讨论、论文阅读、实验复现、系统开发与写作审阅共同推进研究。

### 期待这样的你

- 对科研有真实、持续的兴趣，而不只是希望获得一段经历；
- 认可自己选择的研究问题，愿意理解方向的价值并形成自己的判断；
- 具备基本的科研素养，重视文献、实验、记录、复现与事实；
- 乐于交流，能够清楚表达问题，也愿意接受反馈和参与协作；
- 具备一定的编程基础，愿意借助 AI 工具进行高效的 Vibe Coding；
- 能够保持稳定投入，在不确定、反复与失败中继续推进工作。

### 筛选与考察

加入并非先到先得。为了保证后续协作质量，我们会结合申请材料、线上交流和实践任务进行筛选，主要关注：

1. **科研基本素养**：论文阅读、问题定义、实验设计、结果分析与复现意识；
2. **Vibe Coding 能力**：能否借助 AI 编程工具把想法快速转化为可运行的原型，同时理解、检查并解释代码和实验结果；
3. **动机与方向认同**：为什么选择这个问题，以及是否认可自己正在推进的事情；
4. **沟通与协作方式**：如何表达想法、回应反馈，并在分歧或失败后继续与伙伴推进工作；
5. **持续投入能力**：是否能够为研究留出稳定时间并完成长期协作。

我们不把已有论文或成熟课题作为加入门槛。相比漂亮的经历，我们更希望看到真实的思考、主动的行动和可靠的投入。

### 申请流程

1. 提交申请，介绍你的背景、研究兴趣和可投入时间；
2. 进行材料筛选，了解你的科研思考与过往实践；
3. 通过线上交流或简短任务，进一步了解科研素养与 Vibe Coding 能力；
4. 匹配研究方向与协作伙伴，从一个小而清晰的问题开始。

如果你也希望认真做一些有价值的研究，欢迎[提交 LifeLibra Lab 加入申请](https://docs.qq.com/form/page/DUkFIbHhKV3NjUnRE)。
